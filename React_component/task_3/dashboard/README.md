# School Dashboard - task_3

Task 3 of the `React_component` project: adds reusable `BodySection`
and `BodySectionWithMarginBottom` components. `App` now wraps
`CourseList` and `Login` each in a `BodySectionWithMarginBottom`, and
adds a plain `BodySection` titled "News from the School".

## Setup

```
npm install
```

## Run the dev server

```
npm start
```

## Run the tests

```
npm test
```

## Build for production

```
npm run build
```
