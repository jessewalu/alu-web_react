# School Dashboard - task_1

Task 1 of the `React_component` project: the `App` class now accepts a
`logOut` function prop (default: no-op). On mount it listens for the
`ctrl+h` key combination; when pressed it shows an alert reading
`Logging you out` and calls `logOut`. The listener is removed on
unmount.

## Setup

```
npm install
```

## Run the dev server

```
npm start
```

## Run the tests

```
npm test
```

## Build for production

```
npm run build
```
