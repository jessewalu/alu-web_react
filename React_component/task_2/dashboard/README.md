# School Dashboard - task_2

Task 2 of the `React_component` project: `Notifications` is now a
React class with a bound `markAsRead(id)` method that logs
`Notification $id has been marked as read`. `NotificationItem`'s `<li>`
calls `markAsRead(id)` on click via the `markAsRead` prop it receives.

## Setup

```
npm install
```

## Run the dev server

```
npm start
```

## Run the tests

```
npm test
```

## Build for production

```
npm run build
```
