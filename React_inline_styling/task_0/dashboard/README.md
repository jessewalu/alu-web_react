# School Dashboard - task_0

Task 0 of the `React_inline_styling` project. Copied from the
`React_component` project's `task_5`. `CourseListRow` now applies inline
styling: `#f5f5f5ab` for normal rows and `#deb5b545` for header rows.
The style objects are declared once as module-level constants rather than
being rebuilt on every render.

## Setup

```
npm install
```

## Run the dev server

```
npm start
```

## Run the tests

```
npm test
```

## Build for production

```
npm run build
```
