# School Dashboard - task_2

Task 2 of the `React_inline_styling` project. `NotificationItem` and
`CourseListRow` are converted to Aphrodite and apply their styling
conditionally — urgent vs default notifications, header vs default rows.
The last two stylesheets, `Notifications.css` and `CourseList.css`, are
deleted, so the project now contains no `.css` files at all.

## Setup

```
npm install
```

## Run the dev server

```
npm start
```

## Run the tests

```
npm test
```

## Build for production

```
npm run build
```
