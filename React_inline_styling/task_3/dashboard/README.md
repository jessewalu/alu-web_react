# School Dashboard - task_3

Task 3 of the `React_inline_styling` project. Responsive design via
Aphrodite media queries, targeting screens under 900px wide.

- `Login`: each label/input pair sits on its own line and the button drops
  onto a new line.
- `Notifications`: the open panel covers the whole screen, the `ul` has no
  padding, and the text is 20px.
- `NotificationItem`: full screen width, a black bottom border, 20px text
  and `10px 8px` padding.

## Setup

```
npm install
```

## Run the dev server

```
npm start
```

## Run the tests

```
npm test
```

## Build for production

```
npm run build
```
